# Videos-Edit-Claude

Template de Reels (1080x1920) feito com [Remotion](https://www.remotion.dev).

- Edite textos/cores em `src/Reel.tsx` (`reelSchemaDefaults`).
- Coloque vídeos de fundo / trilhas em `public/`.
- `npm run studio` — editor visual no navegador
- `npm run render` — gera `out/reel.mp4`
